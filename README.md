## 🛠 Featured Projects & Software

- **[B2Arx_Isaac_Sim](https://github.com/wee733/B2Arx_Isaac_Sim):** Isaac Sim digital twin and autonomous inspection navigation overlay for Unitree B2 + ARX R5A.
- **[isaac_ros_manipulation_arx_r5a](https://github.com/wee733/isaac_ros_manipulation_arx_r5a):** A patch-free ROS 2 overlay for physical ARX R5A pick-and-place task.
- **[Isaac_Ros_CuMotion_ArxR5a](https://github.com/wee733/Isaac_Ros_CuMotion_ArxR5a):** Unified ros2_control, MoveIt 2, RViz, and NVIDIA Isaac ROS cuMotion GPU-accelerated motion planning stack for physical ARX R5A.
- **[arx-r5-isaac-sim](https://github.com/wee733/arx-r5-isaac-sim):** Independent simulation execution loop mapping cuMotion/ros2_control to PhysX and state feedback.

For more details on research manuscripts and whole-body control reinforcement learning projects, please visit the [Live Portfolio](https://wee733.github.io/).
